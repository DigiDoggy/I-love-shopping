# Чеклист для проверки: i-love-shopping (1/3)

## Документация проекта

* [ ]  README файл содержит чёткий обзор проекта, ERD, инструкции по установке и руководство по использованию

## Аутентификация и безопасность

* [ ]  Платформа реализует модель электронной коммерции Business-to-Consumer (B2C)
* [ ]  Система поддерживает аутентификацию по email+пароль и через OAuth
* [ ]  CAPTCHA интегрирована в процесс регистрации
* [ ]  Студент может объяснить концепцию JWT и его компоненты (заголовок, полезная нагрузка, подпись)
* [ ]  Access-токены хранятся в памяти
* [ ]  Ротация refresh-токенов реализована с валидацией одноразового использования
* [ ]  Каждый refresh-токен может быть использован только один раз; при обновлении выдаётся новый токен
* [ ]  Старые refresh-токены отклоняются
* [ ]  Реализован механизм отзыва как access-, так и refresh-токенов
* [ ]  Реализована функция восстановления и сброса пароля через email
* [ ]  Двухфакторная аутентификация (2FA) доступна как опциональная функция, включаемая пользователем
* [ ]  Валидация пользовательского ввода реализована как на клиентской, так и на серверной стороне для форм аутентификации

## База данных и масштабируемость

* [ ]  Студент может объяснить особенности масштабируемости выбранной базы данных и то, как они поддерживают рост платформы
* [ ]  Студент может объяснить свойства ACID и их важность в проектировании базы данных e-commerce
* [ ]  ERD предоставлена, чётко показывая сущности, атрибуты, связи, первичные ключи, внешние ключи, кардинальность и модальность

## Каталог товаров

* [ ]  Студент может продемонстрировать и объяснить реализацию поиска, включая проектирование базы данных и базовый текстовый поиск
* [ ]  Модель данных продукта включает все обязательные поля: id, name, description, price, stock quantity, category, brand, images, weight/dimensions (в метрической и имперской системах)
* [ ]  Товары организованы по категориям с интуитивной структурой навигации
* [ ]  Реализован фасетный поиск, позволяющий пользователям уточнять результаты по атрибутам (например, диапазон цен, бренд, категория)
* [ ]  Список товаров включает опции сортировки: релевантность, цена и рейтинг
* [ ]  Изображения товаров хранятся с корректной обработкой файлов и базовым функционалом выдачи
